## 1. Introduction to PHP

### What is PHP?
- **PHP** stands for "Hypertext Preprocessor" (recursive acronym)
- Server-side scripting language designed for web development
- Open source and free
- Created by Rasmus Lerdorf in 1994
- Powers over 77% of all websites (including Facebook, WordPress, Wikipedia)

### Why Learn PHP?
- ✅ Easy to learn for beginners
- ✅ Huge community support
- ✅ Extensive documentation
- ✅ Works well with databases (MySQL, PostgreSQL, etc.)
- ✅ Cross-platform (Windows, Linux, macOS)
- ✅ Powers major frameworks (Laravel, Symfony, CodeIgniter)
- ✅ Great for building dynamic web applications

### How PHP Works
```
1. User requests a PHP page (example.php) in browser
2. Web server sends request to PHP interpreter
3. PHP processes the code and generates HTML
4. Server sends HTML back to browser
5. Browser displays the page
```

**Key Point:** PHP code runs on the **server**, not in the browser. The browser only sees the HTML output.

## 3. PHP Syntax Basics

### Basic PHP Structure

```php
<?php
// PHP code goes here
echo "Hello, World!";
?>
```

**Rules:**
- PHP code starts with `<?php` and ends with `?>`
- Statements end with semicolon `;`
- PHP files have `.php` extension
- You can mix HTML and PHP in the same file

### Example: HTML + PHP

```php
<!DOCTYPE html>
<html>
<head>
    <title>My First PHP Page</title>
</head>
<body>
    <h1>Welcome to PHP</h1>
    <?php
        echo "<p>This paragraph is generated by PHP</p>";
        echo "<p>Current date: " . date("Y-m-d") . "</p>";
    ?>
</body>
</html>
```

### Comments in PHP

```php
<?php
// This is a single-line comment

# This is also a single-line comment

/* 
   This is a 
   multi-line comment
*/

echo "Hello!"; // You can also comment at end of line
?>
```

## 4. Variables and Data Types

### Variables

Variables store data that can be used and manipulated throughout your program.

**Rules for variables:**
- Start with `$` symbol
- Must begin with a letter or underscore
- Can contain letters, numbers, and underscores
- Case-sensitive (`$name` and `$Name` are different)

```php
<?php
$name = "John";           // String
$age = 25;                // Integer
$price = 19.99;           // Float
$isStudent = true;        // Boolean

echo "Name: $name<br>";
echo "Age: $age<br>";
echo "Price: $price<br>";
?>
```

### Data Types

| Data Type | Description | Example |
|-----------|-------------|---------|
| **String** | Text data | `"Hello World"` |
| **Integer** | Whole numbers | `42`, `-10` |
| **Float** | Decimal numbers | `3.14`, `9.99` |
| **Boolean** | True or False | `true`, `false` |
| **Array** | Multiple values | `[1, 2, 3]` |
| **NULL** | No value | `null` |

### String Concatenation

```php
<?php
$firstName = "John";
$lastName = "Doe";

// Using dot (.) operator
$fullName = $firstName . " " . $lastName;
echo $fullName; // Output: John Doe

// Using double quotes (variable interpolation)
echo "My name is $firstName $lastName";

// Using single quotes (no interpolation)
echo 'My name is $firstName'; // Output: My name is $firstName
?>
```

### Common String Functions

```php
<?php
$text = "Hello World";

echo strlen($text);           // 11 (length)
echo strtoupper($text);       // HELLO WORLD
echo strtolower($text);       // hello world
echo str_replace("World", "PHP", $text); // Hello PHP
?>
```

## 5. Operators

### Arithmetic Operators

```php
<?php
$a = 10;
$b = 3;

echo $a + $b;  // 13 (Addition)
echo $a - $b;  // 7  (Subtraction)
echo $a * $b;  // 30 (Multiplication)
echo $a / $b;  // 3.333... (Division)
echo $a % $b;  // 1  (Modulus - remainder)
?>
```

### Assignment Operators

```php
<?php
$x = 10;      // Assign
$x += 5;      // $x = $x + 5;  (now 15)
$x -= 3;      // $x = $x - 3;  (now 12)
$x *= 2;      // $x = $x * 2;  (now 24)
?>
```

### Comparison Operators

```php
<?php
$a = 5;
$b = "5";

var_dump($a == $b);   // true (equal value)
var_dump($a === $b);  // false (equal value AND type)
var_dump($a != $b);   // false (not equal)
var_dump($a !== $b);  // true (not equal value OR type)
var_dump($a > 3);     // true
var_dump($a < 10);    // true
?>
```

### Logical Operators

```php
<?php
$age = 20;
$hasID = true;

// AND - both must be true
if ($age >= 18 && $hasID) {
    echo "Can enter";
}

// OR - at least one must be true
if ($age >= 18 || $hasID) {
    echo "Check further";
}

// NOT - reverses boolean
if (!$hasID) {
    echo "ID required";
}
?>
```

## 6. Control Structures

### If-Else Statement

```php
<?php
$score = 85;

if ($score >= 90) {
    echo "Grade: A";
} elseif ($score >= 80) {
    echo "Grade: B";
} elseif ($score >= 70) {
    echo "Grade: C";
} else {
    echo "Grade: F";
}
?>
```

### Switch Statement

```php
<?php
$day = "Monday";

switch ($day) {
    case "Monday":
        echo "Start of work week";
        break;
    case "Friday":
        echo "Almost weekend!";
        break;
    case "Saturday":
    case "Sunday":
        echo "Weekend!";
        break;
    default:
        echo "Midweek day";
}
?>
```

### Ternary Operator (Shorthand)

```php
<?php
$age = 20;

// Traditional if-else
if ($age >= 18) {
    $status = "Adult";
} else {
    $status = "Minor";
}

// Ternary operator (one line)
$status = ($age >= 18) ? "Adult" : "Minor";
?>
```

## 7. Loops

### For Loop

```php
<?php
// Print numbers 1 to 5
for ($i = 1; $i <= 5; $i++) {
    echo "Number: $i<br>";
}

// Output:
// Number: 1
// Number: 2
// Number: 3
// Number: 4
// Number: 5
?>
```

### While Loop

```php
<?php
$count = 1;

while ($count <= 5) {
    echo "Count: $count<br>";
    $count++;
}
?>
```

### Do-While Loop

```php
<?php
$num = 1;

do {
    echo "Number: $num<br>";
    $num++;
} while ($num <= 5);

// Executes at least once, even if condition is false
?>
```

### Foreach Loop (for arrays)

```php
<?php
$colors = ["Red", "Green", "Blue"];

foreach ($colors as $color) {
    echo "Color: $color<br>";
}

// With index
foreach ($colors as $index => $color) {
    echo "$index: $color<br>";
}
?>
```

### Loop Control

```php
<?php
// break - exits loop completely
for ($i = 1; $i <= 10; $i++) {
    if ($i == 5) {
        break; // stops at 5
    }
    echo $i . " ";
}

echo "<br>";

// continue - skips current iteration
for ($i = 1; $i <= 5; $i++) {
    if ($i == 3) {
        continue; // skips 3
    }
    echo $i . " "; // Output: 1 2 4 5
}
?>
```

## 8. Functions

### Defining Functions

```php
<?php
// Basic function
function greet() {
    echo "Hello, World!";
}

greet(); // Call the function

// Function with parameters
function greetUser($name) {
    echo "Hello, $name!";
}

greetUser("John"); // Output: Hello, John!

// Function with return value
function add($a, $b) {
    return $a + $b;
}

$result = add(5, 3);
echo $result; // Output: 8
?>
```

### Default Parameters

```php
<?php
function greet($name = "Guest") {
    return "Hello, $name!";
}

echo greet();        // Hello, Guest!
echo greet("John");  // Hello, John!
?>
```

### Multiple Return Values (using array)

```php
<?php
function getUser() {
    return ["John Doe", "john@example.com", 25];
}

?>
```

## 9. Working with Forms

### HTML Form Basics

Forms allow users to send data to the server. Two main methods:
- **GET**: Data visible in URL (for searching, filtering)
- **POST**: Data hidden (for passwords, sensitive data)

### Simple Form Example

**form.html**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Contact Form</title>
</head>
<body>
    <h2>Contact Us</h2>
    <form action="process.php" method="POST">
        <label>Name:</label><br>
        <input type="text" name="username" required><br><br>
        
        <label>Email:</label><br>
        <input type="email" name="email" required><br><br>
        
        <label>Message:</label><br>
        <textarea name="message" rows="4" required></textarea><br><br>
        
        <button type="submit">Submit</button>
    </form>
</body>
</html>
```

**process.php**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST['username'];
    $email = $_POST['email'];
    $message = $_POST['message'];
    
    echo "<h3>Form Submitted Successfully!</h3>";
    echo "Name: $username<br>";
    echo "Email: $email<br>";
    echo "Message: $message<br>";
}
?>
```

## 10. Superglobals

Superglobals are built-in variables that are always accessible in all scopes.

### $_GET

Used to collect data sent via URL parameters.

```php
<!-- URL: profile.php?user=john&age=25 -->

<?php
$user = $_GET['user'];  // "john"
$age = $_GET['age'];    // "25"

echo "User: $user, Age: $age";
?>
```

### $_POST

Used to collect data from HTML forms (method="POST").

```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST['username'];
    $password = $_POST['password'];
    
    echo "Username: $username";
}
?>
```

### $_SERVER

Contains server and environment information.

```php
<?php
echo $_SERVER['PHP_SELF'];        // Current script name
echo $_SERVER['SERVER_NAME'];     // Server hostname
echo $_SERVER['REQUEST_METHOD'];  // GET or POST
echo $_SERVER['REMOTE_ADDR'];     // User's IP address
echo $_SERVER['HTTP_USER_AGENT']; // User's browser info
?>
```

### $_REQUEST

Contains data from both $_GET and $_POST.

```php
<?php
// Works with both GET and POST
$name = $_REQUEST['name'];
?>
```

## 11. Practical Examples

### Example 1: Simple Calculator

```php
<!DOCTYPE html>
<html>
<body>
    <h2>Simple Calculator</h2>
    <form method="POST">
        <input type="number" name="num1" required>
        <select name="operation">
            <option value="add">+</option>
            <option value="subtract">-</option>
            <option value="multiply">×</option>
            <option value="divide">÷</option>
        </select>
        <input type="number" name="num2" required>
        <button type="submit">Calculate</button>
    </form>

    <?php
    if ($_SERVER["REQUEST_METHOD"] == "POST") {
        $num1 = $_POST['num1'];
        $num2 = $_POST['num2'];
        $operation = $_POST['operation'];
        
        switch ($operation) {
            case 'add':
                $result = $num1 + $num2;
                break;
            case 'subtract':
                $result = $num1 - $num2;
                break;
            case 'multiply':
                $result = $num1 * $num2;
                break;
            case 'divide':
                $result = ($num2 != 0) ? $num1 / $num2 : "Cannot divide by zero";
                break;
        }
        
        echo "<h3>Result: $result</h3>";
    }
    ?>
</body>
</html>
```

### Example 2: User Registration Form with Validation

```php
<!DOCTYPE html>
<html>
<body>
    <h2>User Registration</h2>
    <form method="POST">
        <label>Username:</label><br>
        <input type="text" name="username" required><br><br>
        
        <label>Email:</label><br>
        <input type="email" name="email" required><br><br>
        
        <label>Password:</label><br>
        <input type="password" name="password" required><br><br>
        
        <label>Confirm Password:</label><br>
        <input type="password" name="confirm_password" required><br><br>
        
        <button type="submit">Register</button>
    </form>

    <?php
    if ($_SERVER["REQUEST_METHOD"] == "POST") {
        $username = $_POST['username'];
        $email = $_POST['email'];
        $password = $_POST['password'];
        $confirm = $_POST['confirm_password'];
        
        $errors = [];
        
        // Validation
        if (strlen($username) < 3) {
            $errors[] = "Username must be at least 3 characters";
        }
        
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            $errors[] = "Invalid email format";
        }
        
        if (strlen($password) < 6) {
            $errors[] = "Password must be at least 6 characters";
        }
        
        if ($password !== $confirm) {
            $errors[] = "Passwords do not match";
        }
        
        // Display results
        if (empty($errors)) {
            echo "<p style='color: green;'>Registration successful!</p>";
            echo "Username: $username<br>";
            echo "Email: $email<br>";
        } else {
            echo "<div style='color: red;'>";
            foreach ($errors as $error) {
                echo "• $error<br>";
            }
            echo "</div>";
        }
    }
    ?>
</body>
</html>
```

## 15. Common Mistakes to Avoid

❌ Forgetting semicolons `;` at end of statements  
❌ Not starting variables with `$`  
❌ Using single quotes when you need variable interpolation  
❌ Mixing up `==` (comparison) and `=` (assignment)  
❌ Forgetting to close PHP tags when mixing HTML and PHP  
❌ Not validating form input (security risk!)
